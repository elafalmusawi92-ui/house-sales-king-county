# House Sales Analysis in King County, USA

## Overview
This project performs exploratory data analysis and regression modeling to predict house sale prices in King County, Washington.

## Key Features
* **Exploratory Data Analysis:** Analyzes relationships between price, square footage, bedrooms, bathrooms, and location.
* **Data Preprocessing:** Cleans missing values, handles feature transformation, and scales data.
* **Predictive Modeling:** Evaluates multiple models including Linear Regression, Ridge Regression, and Polynomial Features.
* **Model Evaluation:** Benchmarks performance using R² score and Mean Squared Error (MSE).

## File
* `House_Sales_in_King_County_USA (1).ipynb`: Main Jupyter Notebook containing analysis and model implementation.
